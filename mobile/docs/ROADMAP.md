# ALEN Mobile Roadmap

## M0 - Bootstrap
- Shared Android/iOS project
- Dark ALEN visual language
- Welcome screen
- Native navigation shell
- CI type checking
- Store-compliance baseline

## M1 - Live Sky
- Connect existing ALEN live-sky renderer
- Match website time and observer state
- Smooth foreground/background resume
- Touch selection and pinch zoom
- Phone-size responsive controls

## M2 - Device Position
- Foreground location
- Manual location
- Compass heading
- Gyroscope and accelerometer
- Calibration UX
- Permission-denial paths

## M3 - Mobile Object Experience
- Native object sheets
- Images and facts
- Distance/depth cues
- Satellites and aircraft
- Search and filters

## M4 - AR
- Camera sky mode
- Real-world alignment
- Drift/calibration correction
- Native privacy and camera permission flow

## M5 - Reliability and Offline
- Local catalogue/cache
- Network-loss handling
- API backoff and cache integration
- Resume without elastic banding
- Battery/memory profiling

## M6 - Store Release
- Final icons and launch assets
- Privacy policy/data map
- Play Data Safety
- Apple App Privacy and privacy manifest
- TestFlight
- Google closed testing where required
- Store screenshots and reviewer notes
- Production release candidate
